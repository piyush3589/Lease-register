================================================================================
HOW TO RUN THE LEASE REGISTER (v3)
================================================================================

You need TWO terminals open at the same time.

  Terminal 1  ->  the API   (this one holds your Groq key)
  Terminal 2  ->  the UI    (what you actually look at)


--------------------------------------------------------------------------------
STEP 1 - CHECK PYTHON
--------------------------------------------------------------------------------

Open any terminal and run:

    python --version

You need Python 3.11 or newer.


--------------------------------------------------------------------------------
STEP 2 - INSTALL THE PACKAGES (only needed once)
--------------------------------------------------------------------------------

    cd "C:\Users\piyush\Desktop\project vantrock v3"
    pip install -r requirements.txt

I already checked on this machine: everything needed is installed.
So you can skip this step.


--------------------------------------------------------------------------------
STEP 3 - CREATE YOUR .env FILE
--------------------------------------------------------------------------------

In PowerShell, from inside the project folder:

    Copy-Item .env.example .env

Then open .env in Notepad:

    notepad .env

Put your Groq key on the first line:

    GROQ_API_KEY=gsk_your_real_key_here
    GROQ_MODEL=openai/gpt-oss-120b
    EXTRACTOR_API_URL=http://127.0.0.1:8001
    EXTRACTOR_API_TOKEN=
    REGISTRY_DB=lease_register.db

Where do I get a Groq key?
    1. Go to https://console.groq.com
    2. Sign up (free)
    3. Click "API Keys"
    4. Create a key and copy it

Save the file and close Notepad.

  If you skip this step, the app still opens, but pressing
  "Extract fields" will show an error saying GROQ_API_KEY is not set.

  KEEP openai/gpt-oss-120b. Do not change it to gpt-oss-20b.
  With 20b the model returns an empty reply, every field comes back
  flagged "unverified", and the evidence is missing.


--------------------------------------------------------------------------------
STEP 3b - IF YOU EDITED .env AFTER STARTING THE API
--------------------------------------------------------------------------------

The API reads your .env file ONCE, when it starts. And --reload watches .py
files, NOT .env.

So if you created or changed .env while the API was already running,
you must stop the API and start it again or you will keep seeing the
old error.

This is the single most common reason for the error
"The API server has no GROQ_API_KEY set" when your .env clearly has one.


--------------------------------------------------------------------------------
STEP 4 - START THE API  (Terminal 1)
--------------------------------------------------------------------------------

Open a terminal. Go to the project folder:

    cd "C:\Users\piyush\Desktop\project vantrock v3"

Start the API:

    python -m uvicorn api:app --reload --port 8001

Wait until you see this:

    Uvicorn running on http://127.0.0.1:8001

LEAVE THIS TERMINAL OPEN. Do not close it or type anything else in it.

Now check it worked. Open a browser and go to:

    http://127.0.0.1:8001/ready

GOOD answer:
    {"status":"ready","model":"openai/gpt-oss-120b"}

BAD answer:
    {"status":"not_ready","reason":"GROQ_API_KEY is not set"}
    -> go back to STEP 3b and restart the API

To stop the API later, press Ctrl + C in this terminal.


--------------------------------------------------------------------------------
STEP 5 - START THE UI  (Terminal 2)
--------------------------------------------------------------------------------

Open a SECOND terminal (keep the first one running). Then:

    cd "C:\Users\piyush\Desktop\project vantrock v3"

Start the UI:

    python -m streamlit run app.py

Your browser should open automatically at:

    http://localhost:8501

If it does not open, copy that address into your browser.

To stop the UI later, press Ctrl + C in this terminal.


--------------------------------------------------------------------------------
STEP 6 - USE IT
--------------------------------------------------------------------------------

The UI has two tabs.

TAB 1: "Extract a lease"

    1. In the dropdown, pick "lease_residential_01.txt"
       (or "(paste my own)" and paste your own lease text)
    2. Make sure the box "Save to the lease register" is TICKED
    3. Press the blue "Extract fields" button
    4. Wait a few seconds
    5. You will see the fields, each with the sentence it came from

    Then try "lease_incomplete_01.txt".
    That one has no landlord and no dates, so those will show
    "not found in document". That is correct behaviour, not a bug.

    You can also upload your own PDF (text-based only, not a scan).

TAB 2: "Register"

    Everything you have extracted so far is listed here.
    - Type in the search box to filter by tenant, filename or any value
    - Select a lease from the dropdown to see its full evidence
    - Press "Download all as CSV" to get a spreadsheet
    - Press "Delete this lease" to remove a row

  Try this: extract "lease_residential_01.txt" twice.
  The second time it says "Already in the register ... refreshed it
  rather than adding a duplicate", and you still only have one row.
  That is intentional.


--------------------------------------------------------------------------------
STEP 7 - RUN THE TESTS (optional)
--------------------------------------------------------------------------------

    cd "C:\Users\piyush\Desktop\project vantrock v3"
    python -m pytest -q

Expected result:

    224 passed

These tests run offline. No API key and no internet needed, and they do
not touch your real register.


--------------------------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------

"GROQ_API_KEY is not set on the API server"
    -> Your .env file is missing, or the key is misspelled, or you did not
       restart the API after editing .env. See STEP 3b. Close the API
       terminal, press Ctrl + C, and start it again.

Everything shows as "unverified" and the evidence is empty
    -> Your model is probably set to gpt-oss-20b. Change GROQ_MODEL in .env
       to openai/gpt-oss-120b and restart the API. See STEP 3.

"Could not reach the extractor API"
    -> Terminal 1 (the API) is not running. Start it again.

port already in use / error on port 8001
    -> Something is already listening on that port, quite possibly an older copy
       of this API that never shut down properly. Find it and stop it:

           Get-NetTCPConnection -LocalPort 8001 -State Listen |
             ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

       If that does not free it (Windows sometimes keeps a dead socket around),
       pick any other port. Start the API with that port, e.g.:

           python -m uvicorn api:app --reload --port 8002

       and in .env set:

           EXTRACTOR_API_URL=http://127.0.0.1:8002

       Remember to restart BOTH the API and Streamlit after editing .env.

"Nothing here yet. Extract a lease in the first tab."
    -> Normal. The register is empty because you have not extracted
       anything with "Save to the lease register" ticked.

The UI says the extractor API is unreachable when you press Extract
    -> Check that Terminal 1 is still running and shows no red errors.

Uploaded PDF gives an error
    -> It is probably a scan (an image of a page). This app reads the text
       layer of a PDF only. It cannot read scans yet.

Everything looks frozen
    -> Press Ctrl + C in both terminals, then start again from Step 4.


--------------------------------------------------------------------------------
WHERE YOUR DATA IS
--------------------------------------------------------------------------------

Everything you extract is saved in this file, inside the project folder:

    lease_register.db

WARNING: this file contains real tenant names, addresses and rents.
It is in .gitignore so it will not be committed to git, but that is not
the same as being protected. Before you share or upload this project
folder, delete this file or encrypt your disk.
